# pb-window

Menu-bar приложение для macOS: хранит историю буфера обмена за последние **24 часа** в зашифрованном виде.
По **⇧⌘V** открывается окно с поиском; выбранная запись кладётся в буфер и автоматически вставляется (⌘V)
в приложение, где вы работали.

## Архитектура

```
app/  SwiftUI + AppKit (меню-бар, всплывающая NSPanel, хоткей, мониторинг NSPasteboard, Keychain, автовставка)
 │  UniFFI (сгенерированные Swift-биндинги + C-заголовок)
core/ Rust `pbcore`: SQLite-хранилище, шифрование, TTL, дедупликация, превью и поиск
```

| | |
|---|---|
| Типы данных | текст, RTF, HTML, изображения (PNG/TIFF/JPEG/GIF, с миниатюрой), файлы (пути) |
| Шифрование | XChaCha20-Poly1305 для каждой записи, превью и миниатюры; AAD привязывает данные к записи |
| Ключ | 256 бит, случайный, хранится в login Keychain (`com.kamaliev.pb-window`); подключи выводятся через HKDF-SHA256 |
| Дедупликация | keyed BLAKE3 — повторное копирование поднимает запись наверх |
| Хранение | `~/Library/Application Support/pb-window/history.db` (права `0600`), `secure_delete=ON` |
| Срок | 24 ч; очистка при запуске и каждые 5 минут, просроченные записи сразу скрываются |
| Лимит | записи больше 20 МБ не сохраняются |
| Приватность | пропускаются данные с типами `org.nspasteboard.ConcealedType`/`TransientType`/`AutoGeneratedType` и т.п. (менеджеры паролей) |
| Ресурсы | опрос `changeCount` раз в 0.5 с с tolerance (данные читаются только при изменении), пауза при сне и блокировке |

В открытом виде в БД лежат только id, тип записи, время и размер.
Если ключ в Keychain удалён, старая история не читается: БД автоматически пересоздаётся.
Если Keychain недоступен, история хранится только в памяти (предупреждение будет в меню).

## Сборка

Нужны Rust (rustup) и Swift toolchain (хватает Command Line Tools, полный Xcode не обязателен).

```sh
make test   # тесты Rust-ядра
make run    # собрать build/pb-window.app и запустить
```

- `UNIVERSAL=1 make app` — universal binary (сначала `rustup target add x86_64-apple-darwin`).
- `SIGN_IDENTITY="Developer ID Application: …" make app` — подпись своим сертификатом (по умолчанию ad-hoc).
- `make xcode` — сгенерировать Xcode-проект (нужны xcodegen и Xcode).

## Разрешения

- **Accessibility** (Системные настройки → Конфиденциальность и безопасность → Универсальный доступ) нужен
  только для автовставки. Без него выбранная запись просто копируется в буфер.
- При ad-hoc подписи каждая пересборка меняет подпись, поэтому macOS может заново спросить доступ к Keychain
  и сбросить Accessibility. С постоянным сертификатом (`SIGN_IDENTITY`) этого не происходит.

## Использование

| Клавиши | Действие |
|---|---|
| ⇧⌘V | показать/скрыть историю (настраивается) |
| ↑ ↓ / ввод текста | навигация / поиск |
| ⏎, двойной клик | вставить |
| ⌘1…⌘9 | вставить запись по номеру |
| ⌘⌫ | удалить запись |
| esc | закрыть |

Окно также можно открыть из скрипта:
`swift -e 'import Foundation; DistributedNotificationCenter.default().postNotificationName(.init("com.kamaliev.pb-window.toggle"), object: nil, userInfo: nil, deliverImmediately: true)'`
